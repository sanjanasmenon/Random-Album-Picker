# Random Album Generator

As someone with a decently large physical music collection, sometimes I run into the conundrum of wanting to put an album on, but not necessarily knowing which one I'm in the mood for. So, I decided to design a site to solve that problem! 

The site takes in personal data about a collection (in the form of a .csv file) and allows for random generation from that list. I experimented with 'PapaParse' as my avenue to read the csv file uploaded by the user. I also played around more with some CSS design elements, some standouts being transitions for the buttons and using my own design skills to upload a drawing I did of a CD case to add a little cosmetic flare. 

Visit the 'Random Album Generator' [here](https://sanjanasmenon.github.io/Random-Album-Picker/Random%20Album%20Picker/)
